# 持仓美元金额与浮动盈亏 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在不增加交易所请求、不触碰交易与风控逻辑的前提下，让统一面板展示网格和对冲持仓的美元金额，并展示真实双腿当前浮盈。

**Architecture:** `tools/run_lighter_hedge.py` 只从当轮 `HedgeState` 的原始持仓对象安全透传三个心跳字段；两个 provider 继续只读本地文件并负责格式化、完整性门槛与 tone。缺失或异常数据只降级单项指标，不抛到交易循环或面板注册表。

**Tech Stack:** Python 3.11、标准库、pytest、OpenSpec。
