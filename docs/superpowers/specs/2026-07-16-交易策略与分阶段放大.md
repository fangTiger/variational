# 交易策略与分阶段放大方案

- **日期**：2026-07-16
- **状态**：阶段 A 执行中，B/C 存档待启
- **关联**：`docs/superpowers/specs/2026-07-15-variational-hedge-bot-design.md`

## 1. 核心策略前提

**靠"持有"赚积分，不靠"交易"。** Variational 积分中持仓（OI）每美元约为成交量的 9 倍
（经验值：持仓 ~86 点/百万/周，成交量 ~9.6 点/百万/周）。因此策略形态是：

> 挑资金费有利的方向，一次开满仓位后**长期持有**，尽量不动。

频繁交易只吃点差+手续费、几乎不涨积分。理想状态一周下单 0 次。

## 2. 关键约束：两腿保证金隔离 → 杠杆有硬顶

组合是 delta 中性（BTC 涨跌不影响总净值），但两个交易所账户独立：任一条腿单独被打穿
= 真金亏掉该腿保证金 + 对冲被破坏、另一腿裸奔。跨所搬保证金走链上、太慢救不了急。
**唯一可靠保护是杠杆别太高。**

| 杠杆 | 单向波动到约多少爆仓 | 评价 |
|---|---|---|
| 2x | ~48% | 保守 |
| **3x** | **~32%** | **默认甜点** |
| 5x | ~19% | 需自动补仓监控才可用 |
| 10x+ | ~9% | 负期望陷阱，禁用 |

**杠杆实用区间 3–5x**。10x 相比 3x 多赚的积分绝对值很小，却带来每周约 5% 的爆仓概率
（≈ 每 20 周亏一腿本金），远不划算。

## 3. 放大积分的四个杠杆（按性价比）

1. **资金量**（主力）：积分随资金线性、安全增长，无爆仓惩罚。因已对冲，加资金只增加
   平台/合约风险，不增加市场风险 → 可比单边投机放心得多地加码。
2. **冷门市场 2× 加成**（免费翻倍）：Variational 冷门/RWA 市场 2× 积分。代价是难对冲，
   需找两所都上的品种、或近似对冲、或小额裸头寸。提升每美元效率，不放大爆仓风险。
3. **适度杠杆 3x**：安全区内的稳定乘数。
4. **推荐返佣**：拉真实朋友合法（返 10%）；自导自演多账号属女巫、禁用（会作废点数）。

**结论**：把积分做大的顺序是 先测收益率 → 加资金 → 叠 2× 加成，杠杆是配角。

## 4. 利润来源：资金费率净差

delta 中性策略利润基本只来自资金费净差。开仓方向挑"我们收费的那边"：哪个所资金费为正
就在哪个所做空、另一所做多，持有期间每小时收资金费，覆盖磨损甚至净赚。
磨损很小（Extended 开+平 taker 共 8bps；Variational 零手续费仅点差）。

## 5. 分阶段放大路径

### 阶段 A（执行中）：跑通 + 实测
- **参数**：每腿 300U，杠杆 **3x**（每腿名义 ~900U），标的 **BTC**，方向选资金费有利侧。
- **目标**：跑通全链路，**实测**真实的每美元积分、资金费净额、磨损，持续 1–2 周。
- **核心产出**：`tracking/` 统计模块给出「每千美元每周积分」「年化资金费」「净盈亏」，
  作为阶段 B 决策依据。
- **安全**：引擎 `dry_run` 默认开启；实盘前先在极小仓位/测试网验证下单字段。

### 阶段 B（存档）：加资金
- 依据阶段 A 实测：若「每美元积分 × $VAR 预期估值 > 资金机会成本 + 平台风险」，则加资金。
- 规模示例：1–3k/腿，杠杆维持 3x。市场风险仍被对冲，主要担合约风险。

### 阶段 C（存档）：叠加冷门市场 2× 加成
- 小仓位、带基差对冲试水冷门/RWA 品种，摸清磨损后再放大。

### 杠杆演进（存档）
- 全程默认 3x。只有在完成"临近爆仓自动减仓/补仓"监控后，才考虑升到 4–5x。

## 6. 阶段 A 参数速查

| 参数 | 值 |
|---|---|
| 每腿资金 | 300U |
| 杠杆 | 3x |
| 每腿名义仓位 | ~900U |
| 标的 | BTC（primary: BTC-PERP / hedge: BTC-USD） |
| 方向 | 选资金费为正的所做空、另一所做多 |
| 下单频率 | 开仓 1 次后长期持有；仅在 delta 漂移>2% / 资金费翻转 / 保证金告急 时动手 |
| 单笔量 | 一次到位（不拆单） |
| dry_run | 是（字段确认+小额验证前不实盘） |
| 观测周期 | 1–2 周 |
