# 设计简报：有界趋势感知网格（bounded trend-aware grid）

> 本文件是给**新会话**的交接 brief。新会话没有此前几天的对话记忆,请先读完再动手。

## 目标（用户诉求）

给现有 Extended BTC 网格加入"**先判断趋势、再决定怎么网格**"的能力。用户看了一个三所网格总控台(参考图 `~/Downloads/temp/123.jpg`),要求复刻其趋势判断思路。

## 参考做法（图中总控台，三所 Decibel/Extended/RISEx，总盈亏+708）

三层趋势处理:
1. **市况分类(regime)**：`市况:震荡 ✓适合跑网格 · 置信度75% / 多周期均显示震荡趋势,斜率接近零,ATR适中`。每所卡片有 `✓趋势一致:震荡(中性网格·强度9%)`。
2. **有界区间**：每个网格有明确 `下边界/上边界`(如 63000/69000,±5%),网格只在区间内铺。
3. **区间外策略**：价格突破边界才动作——`冲破区间平仓`(硬)或 `只减仓回收阶梯`(温和)。附警告"突破边界需及时止损或调整网格"。
- 注：其参数 80~90 格 / ~0.1% 间距 / 25~30x,比我们密得多(单独议题)。其"AI"本质＝多周期斜率+ADX+ATR 指标组合,**无需真 LLM**。

## 与我们已删除的 Donchian 急停的关键区别（务必理解,别重蹈覆辙）

我们 2026-07-21 删掉了 Donchian 96h 突破急停,因为它在**滚动96h新高**上触发→BTC缓漂时几乎每小时误触发→天天撤光网格。
**本设计不同**：用**固定的、宽的、分析定出的区间**,只有价格**真离开该带**才动作,且只处理**亏损那侧库存**,不撤全网格。即"真趋势来了才止损",非"一波动就熄火"。

## 已确认的设计决策

- **区间外策略 = 温和**：突破边界时不硬砸平仓,而是"停止往亏损侧加仓 + 随价格慢慢回收阶梯减仓"(参考 Decibel 的只减仓回收阶梯)。
- **区间 = 自动**：按 ATR 算 `区间 = 现价 ± k×ATR`(k≈1.5~2),重定心时重算。
- **硬底保护**：温和策略下面**必须再垫一道硬止损**(如逼近强平线/最大浮亏阈值就强制平仓),因为当前实盘是 20x 高杠杆,温和不足以防真暴跌。

## 建议实现的四个组件

1. **regime 分类器**（新增,基于现有指标）：多周期收盘斜率 + ADX + ATR% → 输出 `震荡/趋势 + 置信度`。仅当判定"震荡且置信度够"才允许铺中性网格；判定趋势则站一边(撤单/停铺,视温和策略)。
2. **自动区间**：`[现价 − k×ATR, 现价 + k×ATR]`,网格只在区间内铺；k 可配。
3. **区间外温和处理**：跌破下界→停挂新买、随价格回升逐步减多头；涨破上界→停挂新卖、逐步减空头。**外加硬底**:浮亏/保证金逼近阈值→强平止损。
4. **重定心**：突破消化后重新分类；仍震荡→按新价重设区间重铺；转趋势→继续站一边等。
