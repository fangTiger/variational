# 设计：网格趋势感知监控面板（本地 Web，零 LLM）

> 经 brainstorming 确认的设计，供 writing-plans 生成实现计划。日期：2026-07-28。
> 相关：`tools/grid_monitor.py`（现有数据采集）、`grid/regime.py`（趋势指标纯函数）、`grid/grid_engine.py`、`data/grid_state.json`。
> 参考：用户截图的三所"网格交易总控台"（深色卡片式）——我们做**单卡**（自己的 Extended 网格）。

## 目标

一个本地 Web 面板，浏览器打开就能一眼看到当前网格的**市况/趋势、band 区间、盈亏、风险**，看完关掉即可。**趋势判断完全用指标（ADX/多周期斜率/ATR%），零 LLM、零外部 AI**，透明可回测。

## 非目标（YAGNI）

- 不做多账户/多所（只当前 X10_GRID 的 Extended 网格）。
- 不做 LLM 解读（"市况解读"是规则拼句）。
- 不做历史盈亏走势图、不做下单/操作按钮（纯只读看板）。

## 架构与数据流

```
grid_engine 每轮 run_once（30s）
    └─ 末尾 dump 一份 data/grid_live.json（当前实时快照）
tools/grid_panel.py（Python stdlib http.server，无第三方依赖）
    ├─ 读 data/grid_live.json（实时：mode/指标/band/持仓/状态/启动参数）
    ├─ 读 data/grid_monitor.jsonl 最新条（权益/自起始盈亏）
    └─ 渲染深色 HTML → http://localhost:8787，页面 <meta refresh> 每 10s 自动刷新
```

- 面板**不自己连交易所**（快、稳、不占用 API）；数据新鲜度由引擎每 30s 写 `grid_live.json` 保证。
- 权益/盈亏来自 `grid_monitor.jsonl`（monitor 定时快照）；若该文件暂无，面板对应字段显示 `—`，不报错。

## 数据契约：`data/grid_live.json`

引擎每轮末尾原子写（复用 `grid_state` 的原子写思路）。字段：

```json
{
  "ts": 1750000000.0,
  "mark": 63146.0,
  "mode": "neutral",              // neutral(震荡可网格) / off(趋势停铺)
  "adx": 28.4,
  "slope_short": 0.0003,          // 短周期收盘斜率(%/根，价格归一化)
  "slope_long": -0.0001,          // 长周期收盘斜率
  "atr_pct": 0.004,               // ATR / price
  "inv_btc": 0.0,
  "inv_usd": 0.0,
  "band_low": 60620.58,
  "band_high": 65672.30,
  "frozen": false,
  "blocked_side": null,
  "halted": false,
  "dist_to_liq_pct": null,        // 有仓时距强平比例，空仓 null
  "cfg": {"unit": 40, "levels": 4, "max_inv": 160, "spacing": 0.005,
          "hard_stop_dist": 0.12, "adx_off": 30}
}
```

多周期斜率用 `grid/regime.py` 现有 `ema` 算近端斜率（新增一个纯函数 `close_slope(closes, period)`）；ATR% 用现有 `_wilder_atr`。这些在 `run_once_trend_aware` 里已经算了 ADX/ATR，顺带补斜率即可。

## 面板内容（单卡，深色）

1. **顶部条**：进程存活●(读 pgrep 或 grid_live.ts 新鲜度) · 权益 · 自起始盈亏(红绿) · 现价 · 数据时间
2. **趋势卡**（最关心）：
   - 大字市况：`震荡 ✓适合网格` 或 `趋势 · 已停铺`（by mode）
   - 三指标行：`ADX 28.4` · `斜率≈0`（short/long 符号与量级）· `ATR 0.40%`
   - 规则解读一句：如"多周期均震荡·斜率接近零·ATR 适中，适合网格"（纯规则拼句，函数 `describe_regime(...)`）
   - band：`下界 60621 / 上界 65672`
   - **价格位置条**：一根横条标出 band 区间与当前价位置（直观看离哪边界近）；越界时高亮
3. **风险卡**：持仓(BTC/USD) · 距强平% · `frozen/halted` 徽标 · 库存上限
4. **启动参数**：格距/档数/上限/硬止损距/adx_off（from cfg）

## 组件（文件）

- `grid/regime.py`：新增纯函数 `close_slope(closes, period)`（近端归一化斜率）+ `describe_regime(mode, adx, slope_short, slope_long, atr_pct)`（返回中文解读串）。纯函数，可测。
- `grid/grid_engine.py`：`run_once_trend_aware` 末尾 dump `grid_live.json`（新增 `_dump_live(...)`，dry_run 也写——它只是本地文件，方便观察）。非破坏：`trend_aware=False` 不写。
- `tools/grid_panel.py`：stdlib `http.server` 小服务 + HTML 渲染函数 `render_html(live: dict, equity_snap: dict) -> str`（纯函数，可测）。CLI：`--port 8787`。
- `tests/test_panel.py`：`close_slope`/`describe_regime` 纯函数、`render_html` 给定状态含关键字段/越界高亮、`grid_live.json` 缺失时面板降级不崩。

## 错误处理

- `grid_live.json` 缺失/损坏 → 面板显示"引擎未运行或无数据"，不崩。
- `grid_monitor.jsonl` 缺失 → 权益/盈亏显示 `—`。
- 数据时间超过 N 秒(如 90s)未更新 → 顶部存活●变灰 + 提示"数据可能过期"。

## 非破坏

- 引擎写 `grid_live.json` 是纯新增，只在 `trend_aware=True` 路径末尾；不影响下单/风控逻辑。
- 面板是独立工具，不常驻、不连交易所、不参与交易。
