# Variational Swap Carry 对冲方案

> 状态：**取证阶段，禁止开正式仓**。
> 依据：`openspec/changes/variational-swap-carry/`（已过三方评审收敛）。
> 数据基准：2026-09-04T16:38Z 实测。

## 一、结构定义

同一 Variational 账户内，同一底层（黄金现货）的两种合约类型之间做 delta 中性：

| | 腿 A | 腿 B |
|---|---|---|
| 标的 | **XAUS** — Swap on Gold Spot | **XAU** — 黄金永续 |
| `instrument_type` | `swap` | `perpetual_rwa_future` |
| `kind` | `commodity` | `commodity` |
| `funding_interval_s` | **0**（必须） | 3600 |
| v1 方向 | **做多** | **做空** |
| 保证金模式 | **isolated** | 全仓 |
| IM / MM | 5% / 2.5% | 5% / 2.5% |
| 强平空间 | **±2.56%**（放大 qty 不变） | ±17% |
| 计息 | 每日 21:05Z 离散一次 | 每 4h 连续 |
| 交易时段 | 见 §五，**周末休市 49h** | 24/7 |

两腿等名义反向 → 净 delta = 0，金价涨跌不赚不亏。
收益来源 = 两腿资金费之差（永续是供需价，swap 是 OLP 定的类 SOFR 固定价）。

**注意：两腿不是同一参考价的 delta-1 对冲。** 实测 XAU `index` 与 XAUS `index`
差 2.23bp、`mark` 差 8.12bp，基差本身是独立风险项（§三）。

## 二、经济模型

### 2.1 收益公式（两腿计息节奏不同，禁止对净 carry 统一乘同一系数）

```
weekly_flat:   R = f_perp × 0.705 − f_swap × (4/7) − 52 × c
hold_through:  R = f_perp − f_swap − n_rebalance × c
```

- `f_perp`：XAU 永续年化费率（我方做空 → 正值为收）
- `f_swap`：XAUS 多头年化成本（当前 5.7214%）
- `0.705` = 118.5h / 168h（周日 22:00Z 开市 → 周五 20:30Z 冻结前平仓）
- `4/7` = 周末平仓下只承担周一~周四 4 次 21:05Z 计提
- `c` = 双腿一次完整往返成本，**规划口径 6bp**（实测 4.44bp + 1.5bp 滑点缓冲）

**跳过的成本比例（42.9%）> 跳过的收入比例（29.5%）→ 周末平仓在费率结构上部分有利。**

### 2.2 往返成本（实测，qty=0.224 ≈ $1000/腿）

| | 完整点差 |
|---|---|
| XAUS | 1.353bp |
| XAU | 3.087bp |
| **双腿一次往返** | **4.44bp** |

两个市场的 `mark_price` 精确等于盘口中点，故公允价即中点；
**一条腿开+平只跨一次完整点差**（买 ask、卖 bid），不是两次。
手续费 `futures_taker_fee = 0`。

### 2.3 当前经济性（2026-09-04T16:38Z）

`f_perp = 10.2888%`、`f_swap = 5.7214%`、净 carry = 4.567%/年

| 政策 | 成本口径 | R（年化名义） | $1000/腿的绝对收益 |
|---|---|---|---|
| weekly_flat | 6bp | **+0.86%** | $8.6/年（$0.024/天） |
| weekly_flat | 4.44bp | +1.68% | $16.8/年 |
| hold_through | 4.44bp × 4次/年 | **+4.39%** | $43.9/年（$0.12/天） |

**政策选择带来约 5 倍收益差，比阈值调优重要一个数量级。**

## 三、被忽略过的风险项：基差

实测 XAU `price` 4438.64 vs XAUS `price` 4435.04 → 永续高 **8.12bp**；
两者 `index_price` 也差 **2.23bp**。

每周平仓一次会把基差波动**变成已实现盈亏**：单周期损益含 `−Δ(XAU − XAUS)`。
若每次往返基差漂移 ±5bp，年化即 **±2.6%**——与整个净 carry 同量级，比点差成本还大。

持有过周末不消除基差风险，但把 52 次已实现基差噪声降为约 4 次。
**这是 hold_through 相对 weekly_flat 最强的量化论据。**

## 四、入场门槛（从成本模型推导，不是拍的）

阈值对**扣除全部摩擦后的收益 R** 设定，政策作为 R 的输入：

```
入场：7 日中位 R ≥ 6%/年  且  R ≥ 3 × 年化摩擦
退出：7 日中位 R ≤ 0 持续 24 小时
硬退出：f_perp < f_swap 连续 3 个结算周期
滞回：入场后承诺 min_commit_cycles = 3 个周循环（禁用「最短持仓 N 天」形式）
豁免：周末平仓 / 单腿失衡 / ADL / kill switch / 地区封锁 MUST 无条件豁免持仓期约束
```

反推所需的 `f_perp`（f_swap = 5.7214%）：

| 政策 | c | 年化摩擦 | R ≥ 6% 需要 | R ≥ 3×摩擦 需要 | **实际门槛（取高）** |
|---|---|---|---|---|---|
| weekly_flat | 4.44bp | 2.31% | 16.42% | 17.74% | **17.7%** |
| weekly_flat | 6bp | 3.12% | 17.57% | 22.34% | **22.3%** |
| hold_through | 4.44bp | 0.18% | 11.90% | 6.43% | **11.9%** |
| hold_through | 6bp | 0.24% | 11.96% | 6.68% | **12.0%** |

**当前 f_perp = 10.29%，低于任一门槛 → 不得开正式仓。**

> ⚠️ 「R ≥ 3×摩擦」这条规则在 hold_through 下失去意义（摩擦仅 0.24%，
> 3 倍也只有 0.72%），此时 R ≥ 6% 成为唯一约束。
> **hold_through 的真实风险不是交易成本而是周末跳空，
> 需另行设定与尾部风险挂钩的安全边际，不能沿用「3×摩擦」。这是待定的设计决策。**

## 五、交易时段（禁止任何固定时钟假设）

XAUS 实测 `trading_sessions`：
```
open 09-02T22:00Z → close 09-03T21:00Z   (23.0h)
open 09-03T22:00Z → close 09-04T21:00Z   (23.0h)
open 09-06T22:00Z → close 09-07T18:30Z   (20.5h)  ← 劳动节，18:30 收市
```

- 常规：每日 21:00~22:00Z 休市 1 小时
- **周五 21:00Z ~ 周日 22:00Z 连续休市 49 小时**
- **下周一 09-07 是 18:30Z 收市，不是 21:00Z。** 市场上线仅 5 天日历已不规则
- 当天 21:05Z 的资金费计提落在收市之后，计费归属未知
- **实现必须解析 `trading_sessions`，写死 21:00Z 上线第一周就会错**

## 六、判决性未决问题（决定这个方案能否成立）

### 6.1 【最高优先级】XAU 是否存在 +10.95%/年 资金费硬顶

账户全部 536 条已结算资金费统计：

| 合约类型 | 观测数 | 最大年化 | 正好 = 10.95% | **超过** |
|---|---|---|---|---|
| `perpetual_future`（15 标的） | **528** | 10.950% | 204 | **0** |
| `perpetual_rwa_future`（SNDK） | 8 | **48.789%** | 0 | **6** |

`+10.95%/年 = 0.0001/8h`，即行业标准基准费率。**0 条突破、204 条压线 = 硬帽。**

- **若 XAU 也在帽下 → `f_perp ≤ 10.95%`**，代入各政策：
  - weekly_flat：`R ≤ 10.95×0.705 − 5.7214×4/7 − 3.12 = +1.33%/年` → 远低于 6% 门槛
  - hold_through：`R ≤ 10.95 − 5.7214 − 0.24 = +4.99%/年` → 仍低于 6% 门槛
  **两种政策下都永远无法达到自己的入场条件 → 立即终止。**
  注意 hold_through 的裕度只差约 1 个百分点，
  若届时下调门槛则需重新论证，不能因为"接近"就放行。
- XAU 是 RWA 类，同类 SNDK 已印 48.79%，**大概率不受限**
- **但 XAU 本身的账户历史样本数 = 0**。XAUT/PAXG 虽是黄金代理，
  但它们被封顶而 XAU 没有，**在上行方向是错误代理**

### 6.2 swap 多日计提方向（二值，摆动幅度大于点差之争）

- 若周五 21:05Z 一次收 3 天 → 周末平仓躲掉全部三天，swap 系数 = **4/7**（本方案假设）
- 若周一 21:05Z 追补 Sat/Sun → 实付 **6/7**，成本多 `5.72% × 2/7 = +1.63%/年`

**结论相反，必须用探针仓跨一个周末实测。**
不得用「rate 是否为 3 倍」判定——`long_rate` 是年化率，
覆盖多天应体现在扣款金额（coverage_days）上，不在 rate 上。

### 6.3 XAUS 真实 IM

`/settlement_pools/leverage` 报 XAUS 在 0–2M 档 `min_im 0.10 / min_mm 0.05`，
而 `/quotes/indicative` 按 0.05 / 0.025 返回（强平空间 2.56%）。**两者矛盾，需实测。**

### 6.4 反身性

24 小时内实测变化：

| | 09-04 早 | 09-04 16:2xZ |
|---|---|---|
| XAU 永续费率 | 18.87% | **9.94~10.29%** |
| XAUS 多头 OI | $24.1M | **$27.7M（+15%）** |
| XAU 永续空头 OI | — | **$29.2M，已反超多头 $25.6M** |

三个信号方向一致 = 套利资金涌入压低永续费率的教科书图景。
**需持续观察 f_perp 是否收敛到 f_swap（5.72%）附近的地板；若是，该结构按构造已死。**

## 七、执行计划

### 阶段 0：只读采样（立即开始，无成本，可能单方面终结方案）

每小时采集并落盘：
- XAU `predicted_funding_rate`、XAUS `long_rate`/`short_rate`
- 两腿 OI（多/空）
- 基差：`XAU.mark − XAUS.mark`、`XAU.index − XAUS.index`
- 固定名义（$1000）RFQ 双边点差
- `trading_sessions` 与字段新鲜度

**判据**：
- 若 f_perp 反复精确停在某常数（尤其 10.95%）→ **终止方案**
- 若 f_perp 收敛到 5.72% 附近 → **终止方案**
- 若 f_perp 出现稳定高于 15.3% 的地板 → 进入阶段 2

### 阶段 1：生产 bug 修复（与本方案解耦，独立优先）

1. **Extended 侧资金费单位校准** — `tracking/monitor.py:52` 的「小数/1 小时」
   假设从未校准，会翻转现有 BTC 结构的方向建议
2. **仓位查询强制 `exact=True`** — `get_position("XAU")` 会子串命中 `XAUS`，
   **只要碰 XAUS（哪怕 $5 探针仓）就会踩**；弃用 `get_liquidation_info` 自算

### 阶段 2：$5 探针仓（手工执行，须在放行 IP 上，不为它建状态机）

`XAUS min_qty = 0.00003` 盎司 ≈ $0.13，探针成本极低。一次性验证：

1. 先开 XAUS 腿（受限：休市 + isolated）
2. 回读确认成交数量 Q（容忍 `/positions` 最终一致延迟，勿据即时读仓判定）
3. 按 Q 等值名义开 XAU 空腿
4. 第二腿失败 → 立即 `reduce_only` 回滚第一腿
5. 回滚也失败 → 停止一切动作、告警、人工介入

### 阶段 3【冻结】：生产化

解冻条件（须**同时**满足）：
1. 阶段 0 证明 f_perp 存在稳定高于 15.3% 的地板且无硬顶
2. 账户可投资金 ≥ $10k

**理由**：持久化状态机/故障矩阵/崩溃恢复不是为保护收益，而是防
「第一腿成交后崩溃、裸 isolated 腿跨 49 小时休市」——
一次事故损失约 1~3 年全部利润。**工程量下限由失败模式决定，不由 P&L 决定；
所以正确答案是暂不跑这个策略，而不是把工程做薄。**

> `tools/run_swap_carry_guard.py`（原设计为人工值守，不含自动风控）。

### 8.3 强制风控

- **硬名义上限 + kill switch**（参照 `tools/hedge_gold.py` 的 `MAX_NOTIONAL`）
- **pre-close 冻结窗口**：距 `trading_schedule.next_close_at` 不足 30 分钟
  禁止任何开仓/加仓 —— 否则第二腿失败时无法在休市前回滚，
  会留下 49 小时裸 isolated 腿
- **休市期间禁止开仓**，但不得关闭对既有仓位的监控
- **swap 腿因休市取不到报价属正常状态**，
  SHALL NOT 触发「数据不可得即平掉两腿」——那只会平掉永续腿、留下裸 swap 腿
- **单腿失衡**：检测到只剩一条腿 → 立即平掉剩余腿（永续 24/7 可平）+ 告警 + 停机，
  禁止自动重建
- **开市健康检查**：开市后取不到可成交报价或点差超阈值 → 不交易 + 告警
- **`is_close_only_mode` 为真** → 禁止开仓，只允许减仓

### 8.4 周末尾部的量化（支持未来重估 hold_through）

XAUS 多头强平在 −2.561% 的同一时刻，XAU 空腿浮盈 +2.561%，两者高度对冲。
isolated 桶 = 名义 5%，触发时余 MM 2.5%，`liquidation_penalty = 0.1`
→ 净实际损伤约 **1% 名义量级**，且留下的是一条 **24/7 可随时平掉**的空腿。

**「单腿爆仓后另一腿也平不掉」这个最坏状态并不成立。**
即周末风险是「低概率、约 1% 名义的有界止损」，不是灾难。
但在 §6.2 有结论前，政策一律保持 `weekly_flat`。

## 九、终止条件

出现任一条即归档终止，不再投入：

1. f_perp 被证实存在 +10.95%/年 硬顶
2. f_perp 收敛到 f_swap（5.72%）附近的地板
3. 采样 30 天后，保守口径 R < 5%/年
4. §6.2 证明周一追补 Sat/Sun 且 weekly_flat 下 R 转负，同时 hold_through 前置条件不满足
