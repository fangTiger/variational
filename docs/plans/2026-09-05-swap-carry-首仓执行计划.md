## 三、执行步骤

### T-0：开市（2026-09-06T22:00Z ＝ 北京时间周一 06:00）

**1. 预检**
```bash
python -m tools.hedge_swap_carry status
```
确认：XAUS 时段=可交易、净 carry ≥ 5%、账户无异常持仓。

**2. 空跑**
```bash
python -m tools.hedge_swap_carry open --notional 50 --dry-run
```
确认两腿报价正常、数量与名义对得上。

**3. 偏斜试探（$50）**
```bash
python -m tools.hedge_swap_carry open --notional 50 --yes
```
- **通过** → 立即平掉，进入第 4 步。说明 XAUS 多头方向接单
- **被拒（HTTP 422 skew）** → **本周不做**，XAUS 多头开不进去。
  记录并等待偏斜缓解；不要反复重试（限流罚分制，11 次以上封 24 小时）
- 任何重试间隔 ≥30 秒

**4. 建仓**
```bash
python -m tools.hedge_swap_carry open --notional 2000 --yes
```
偏斜既然在 $50 通过，$2,000 在偏斜之外没有别的墙
（分档表要到 $2M 才降杠杆）。不需要中间档。

**5. 交回风控**
```bash
launchctl load ~/Library/LaunchAgents/com.variational.swap-carry-guard.plist
python -m tools.hedge_swap_carry status   # 确认「守护进程上次运行于 N 分钟前」为绿
```

### 持有期间

守护进程每 5 分钟自动处理，**无需人工干预**：
- 周五休市前 30 分钟自动平两腿
- 单腿失衡 → 平掉剩余腿
- XAUS 强平距离 < 1.5% → 平两腿
- 强平价/名义价读不到、时段元数据陈旧 → 一律按不安全平仓
- kill switch 文件存在 → 平仓并停机

**人工只需每周看一次** `status`，重点看两行：
- `守护进程上次运行于 N 分钟前` —— 超 15 分钟会标红（无声停摆的唯一发现手段）
- 净 carry 是否仍 ≥ 0

### 紧急停止
```bash
touch data/swap_carry.kill      # 守护进程下一轮即平仓并停机
python -m tools.hedge_swap_carry close --yes   # 或立即手动平
```

## 四、这一仓要买到的三个答案

$2,000/腿在 carry 10% 时是 $0.55/天。**收益不是目的，数据才是。**
这一周要解决三个至今无法从纸面得出的问题：

1. **OI 偏斜墙**：XAUS 多头（偏斜已 +59%）还接不接单
2. **swap 计息方向**（方案 §6.2 的二值未知）：
   周五 21:05Z 预收 Fri/Sat/Sun 三天，还是周一 21:05Z 追补 Sat/Sun？
   两种情况下 weekly_flat 的成本差 1.63%/年，结论相反。
   **只能靠 `/transfers` 的实际扣款金额回答**
3. **XAUS 真实 IM**：分档表报 `min_im 10%`，报价按 5% 返回（方案 §6.3）。
   决定强平距离是 2.56% 还是 5.26%

答完再谈放大，那时才有依据。

## 五、已知未验证的风险（接受并记录）

- **XAUS 隔离腿 2.56% 强平线从未实盘穿过一个周期**。金价一周跌 2.56% 是常见事件
- 周末 49 小时不可交易期间**无法补保证金、无法平仓**（故 v1 周末不持仓）
- 无远程告警：出现需人工介入的情况（403 封锁、回滚失败）时不会主动通知，
  只能靠 `status` 的心跳标红发现
- 执行层代码只做过一次真实往返验证（XAU 单腿开平 + 第二腿失败回滚），
  XAUS 腿从未真实成交过
